# 优学院自动化刷题刷课工具

## 特色功能

简单易用，app内嵌自动化刷课脚本，无需二次手动设置。自动识别网址，自动答题

## 使用方法

1.下载安装https://nodejs.org 

2.chrome-win64文件夹复制到c盘根目录

- **Mac/Linux**：运行 `bash start.sh`
