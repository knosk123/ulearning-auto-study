# 优学院自动化刷题刷课工具

## 特色功能

简单易用，第一次操作稍微麻烦，但是一劳永逸。app内嵌自动化刷课脚本，无需二次手动设置。自动识别网址，自动答题

## 使用方法

### 1. 安装 Node.js
如果没有，去 https://nodejs.org 下载安装。并配置相关环境变量（不会就去问ai）

### 2. 克隆仓库
git clone 
git@github.com:knosk123/ulearning-auto-study.git

### 3. 安装依赖
npm install

### 4. 运行
- **Windows**：双击 `start.bat`
- **Mac/Linux**：运行 `bash start.sh`

### 5. 注意
需要自行下载chrome，地址为C:\chrome-win64\chrome.exe（以防脚本找不到你的浏览器）
